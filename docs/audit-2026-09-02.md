## Competitive analysis update

Проведен внешний рыночный review. Для документации использованы текущие публичные данные по нескольким категориям: no-signup website scanners, target-based vulnerability platforms, EASM/infrastructure monitoring и public Internet posture tools.

Зафиксированы изменения:

- Change Intelligence становится first-class product capability.
- Asset attribution/provenance и graph-ready relations нужны раньше AppSec.
- Agency/MSP строится через delegated access между отдельными tenants.
- Guest Scan должен быть полезным posture report, но не раскрывать active vulnerability details.
- A-F grade не используется как основной security abstraction.
- Billing остается asset-based, без credits за обычные repeat scans.
- UI разделяется на business summary и technical drill-down.

### Security impact

Agency/MSP решение уменьшает будущий blast radius: клиенты не смешиваются в одном partner tenant. Для реализации обязательны delegation authorization и cross-client negative tests.

Change Intelligence увеличит объем исторических данных, поэтому до production необходимо определить retention и storage/query strategy для posture snapshots.
