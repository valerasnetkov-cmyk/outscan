## Canonical GUEST_SAFE ScannerResultEnvelope producer

- Added `apps/api/src/scanner-output/canonical-guest.ts` on top of the existing bounded strict Guest parser. It snapshots the input before validation and never canonicalizes unvalidated scanner JSON.
- The producer constructs one minified UTF-8 JSON representation with fixed top-level/record field order and ordinal sorting for observations, candidate findings, coverage and warnings. Input property and collection order no longer changes payload bytes, digest or size.
- Every free-form candidate evidence value is replaced with `[REDACTED:UNTRUSTED_EVIDENCE]` before serialization and SHA-256. Negative fixtures prove that a CVE, internal endpoint, markup, CRLF/log content and spreadsheet formula do not survive into authenticated canonical bytes.
- The result exposes only frozen metadata/public projection plus copy-on-read canonical payload. Mutating one returned copy cannot alter later reads, digest or size.
- Added an integration test that authenticates canonical bytes through the ResultEnvelope HMAC verifier and another that re-projects them to the identical sanitized Guest result.
- Hardened the existing Guest warning validator to reject duplicate machine warning codes, aligning implementation with the documented closed-schema rule.

## Bounded scanner local IPC protocol

- Added `apps/api/src/scanner-ipc` with a fixed `OUTSCAN:SCANNER_RESULT:v1\0` magic, U32BE payload length and exactly-one-payload-plus-EOF contract.
- The active profile byte ceiling is validated before allocating declared payload storage. Empty, invalid, incomplete, oversized, trailing and concatenated frames fail closed.
- One wall-clock deadline covers header, body and required EOF. AbortSignal cancellation and timeout request best-effort iterator termination; thrown/non-byte streams return stable errors without upstream detail.
- Fragmentation is capped at 4096 chunks, including empty chunks, so a bounded byte payload cannot create unbounded scheduling/loop work.
- Encoder and reader copy caller/stream bytes. Successful output is frozen metadata with copy-on-read payload, preventing later mutation of the accepted IPC snapshot.
- Added synthetic async-iterator tests for split headers/payloads, magic/length encoding, early EOF, frame smuggling, oversized declaration, fragmentation, stream errors, cancellation, timeout, exact hostile options and input-copy isolation.
- Added an integration test from one IPC frame into strict canonical GUEST_SAFE production. No child process, OS pipe, container, queue, external network or ResultEnvelope signing was invoked.
